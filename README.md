# 🗳️ Student Online Voting System

## 📌 Description
The Student Online Voting System is a web-based application developed to conduct student elections efficiently, securely, and transparently within educational institutions. The system allows students to vote online and enables administrators to manage elections and view results in real-time.



## 🎯 Objective
- To provide a secure and transparent voting system  
- To reduce manual effort in conducting elections  
- To ensure fair and accurate vote counting  
- To improve accessibility for students  



## 🚀 Key Features

### 👨‍💼 Admin Module
- Admin login authentication  
- Create and manage elections (President, Vice President, etc.)  
- Add candidates  
- Set election start and end time  
- View voting statistics  
- Display results using charts  

### 👩‍🎓 Student Module
- Student registration and login  
- View elections (ongoing, upcoming, completed)  
- Cast vote securely  
- One student → one vote system  
- View confirmation after voting  



## 🌐 User Interface Features
- Attractive homepage with navigation  
- About section  
- News ticker for updates  
- Candidate spotlight section  
- Voting statistics display  
- “How to Vote” guide  
- Responsive design  



## 🛠️ Technologies Used
- Frontend: React.js  
- Backend: Node.js, Express.js  
- Database: MongoDB  
- Languages: HTML, CSS, JavaScript  



## 🏗️ System Architecture
- Frontend handles UI and user interaction  
- Backend manages API and business logic  
- MongoDB stores user, candidate, and voting data
